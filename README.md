A small Node program that hands in the address of an X post. The post is a GTA 6 meme with make.fun in the picture, posted from a public X account, telling readers they can earn money on make.fun.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
